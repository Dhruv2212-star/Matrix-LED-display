# What is it? 
A simple 8x8 LED arrangment that uses MAX7219 LED driver to controll each LED individualy and uses RP2040 to store the code and  
send the data to Driver to create the image
# How to use it?
write a code in C++ and flash it onto the RP2040 to create the paterns onto the LED matrix
